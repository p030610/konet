Challenge description / KoNet

한국어 발화의 작은 시간차를 구별하기

음성과 입 모양의 시간 정합성을 판단하는 audio–visual synchronization challenge

Task & pipeline

입력 쌍에서 동기화 점수까지

같은 발화의 입 주변 영상 16프레임과 음성 mel을 입력받아 하나의 유사도 점수를 출력합니다. 두 인코더가 각각 2048차원 특징을 만들고 cosine similarity로 결합합니다.

영상·음성 전처리 → 독립 인코더 → 유사도 점수 → 중심과 ±시간차 비교 순서로 평가합니다. 한국어 더빙과 애니메이션 생성에 쓸 감독 신호를 만드는 것이 장기 목표입니다.

Baseline & target

같은 입력에서 세 checkpoint 비교

공식 StableSyncNet 원본, 한국어 Full fine-tuning epoch 9, LoRA rank 8·alpha 16 epoch 5를 비교합니다. 주 비교는 held-out 공통지원 코호트의 80ms strict both-win이며, 6개 시간차와 최소 margin도 함께 확인합니다.

참가 모델은 고정 split과 입력 전처리를 따르고, 동일한 B-window의 중심·음·양 세 점수를 제출하는 방식으로 비교할 수 있습니다. 현 단계는 완료된 세 모델의 오프라인 평가입니다.

01B / Recorded supervisor scores

시간 이동에 따라 달라지는 감독 점수.

정합 입력 → 같은 한국어 음성 → 의도적으로 시간 이동한 입력

기록된 점수 비교 아래는 한국어 입력의 기존 cosine 측정값입니다. 평가 데이터는 AIHub 공식 신청·승인 경로로 접근할 수 있습니다.

선정된 감독 점수 비교 사례 1개 · AIHub 538 C293 개발 validation. 동일 음성에 영상 시작점만 바꾼 16프레임·0.64초 평가 창의 점수입니다.

원본 StableSyncNet의 기록된 cosine 점수 · 높을수록 정합으로 판단
입력 조건평가 label점수
동일 녹화의 정합 입력 · 0ms1 · 정합0.2321
영상만 640ms 이른 구간 · −640ms0 · 비정합0.6257 · 더 높음
시간 이동의 방향·점수 측정 구간·원점수 근거

실제 평가 입력 — window ID TS10:C293:J:1:F:03:002:noise=1:48. 공통 음성 시작은 30,720sample / 16kHz = 1.92초입니다. 정합 영상은 48/25 = 1.92초, 이동 영상은 32/25 = 1.28초부터 시작합니다. 따라서 Δ = 영상 시작 − 음성 시작 = −640ms이며, 음성이 영상보다 640ms 앞서는 조건입니다.

영상과 점수의 범위 — 모델은 정렬된 lower-half RGB와 mel52열을 사용했고, mel에는 기준점−25ms부터 +662.5ms까지의 파형 문맥이 포함됩니다.

후보 C032는 음량이 매우 작아(mean −49.5dBFS) 무음의 영향이 섞일 수 있으므로 제외했습니다. C293는 입의 발화 움직임과 음량(mean −21.0dBFS)을 확인했으나 음소별 정답 검증은 별도입니다. 원본 녹화의 label 1은 평가 데이터의 정합 가정이며, 절대 A/V offset의 독립 인증과 구분합니다.

기록된 점수의 해석 원본 녹화 기준점보다 −640ms 입력의 cosine 점수가 높았습니다. 녹화 자체의 A/V offset도 영향을 줄 수 있으므로, 다음 집계에서는 A-fold로 중심을 선택한 뒤 별도 B-fold를 비교합니다.

04 / What the metrics mean

시간차, 분류, 점수를 따로 봅니다.

↑ 높을수록 좋음 · ↓ 낮을수록 좋음

Timing · Primary

Signed80 ↑

같은 음성에 정합 영상, −80ms 영상, +80ms 영상을 짝짓습니다. 원래 정합 점수가 이동한 점수보다 높은지 두 방향을 각각 비교합니다.

Signed80 = ½ × [win(−80) + win(+80)]

예: s₀=0.7, s₋₈₀=0.6, s₊₈₀=0.8 → 한 번 승리, 한 번 패배 → 50%. 분류 threshold와 독립적인 순위 지표입니다.

Classification · Balanced

Balanced accuracy ↑

점수가 threshold 이상이면 정합, 미만이면 비정합으로 분류합니다. 각 클래스의 정답률에 같은 가중치를 줍니다.

BA = ½ × [정합 recall + 비정합 recall]

예: 정합 90%, 비정합 70% 정답 → 80%. 전부 비정합이라고 답하면 일반 정확도는 90.9%지만 BA는 50%입니다.

Score quality · Loss

Balanced BCE ↓

정합에는 높은 점수, 비정합에는 낮은 점수를 주는지 평가합니다. 틀린 쪽에 확신할수록 벌점이 커집니다.

BCE = ½ × [mean(−log s₊) + mean(−log(1−s₋))]

정합·비정합 손실을 균형 평균합니다. cosine 점수를 clipping한 진단값으로, 실제 보정 확률과는 구분합니다.

정확한 집계와 해석

Signed80의 점수 차이가 1e-6 이내면 0.5승입니다. window → 녹화 → 화자 평균으로 긴 영상이나 특정 화자의 쏠림을 줄입니다. BA의 threshold는 각 모델의 validation에서 정합니다. 비정합에는 ±80ms 외의 시간 이동도 포함됩니다.

Signed80 65%는 “영상의 65%가 정확히 동기화됐다”는 뜻과 다릅니다. 실제 AV 시작점의 절대 정답과 언어별 일반화는 별도의 평가 과제입니다.

Held-out 평가 · strict both-win

Frozen center / matched inputs

A-fold 선택 → B-fold 평가

원본 A-fold 평균 cosine 점수로 선택한 중심을 고정하고 모든 모델에 같은 B-window를 사용합니다. 원본과 두 적응 모델 모두 같은 1280×720 정규화 입력 정책을 적용했습니다.

48개 held-out 기록 중 44개가 valid 중심이며 4개 boundary 기록은 제외했습니다. 4명 화자·96개 B-window가 6개 거리 모두에서 공통지원됩니다.

Strict paired score comparison

양쪽 시간차를 모두 이겨야 성공

win = (s₀ > s₋ + 1e−6) AND (s₀ > s₊ + 1e−6)
margin = s₀ − max(s₋, s₊)

동점은 실패입니다. 유효한 3점 triplet을 창 → 기록 → 화자 순서로 평균하여 화자를 동일가중 집계합니다. 개발 Signed80은 양방향 승리의 평균·동점 0.5승이므로 별도 지표입니다.

05 / StableSyncNet architecture

입과 소리에서, 하나의 동기화 점수로.

두 encoder가 각각 특징을 만들고, 마지막에 얼마나 닮았는지 비교합니다.

논문 근거와 실제 layer 구성 보기

LatentSync 논문 §3.3의 SD 계열 encoder 설계와 실제 사용 중인 attention 설정을 기준으로 다시 그렸습니다. 논문은 attention 제거 실험도 다루지만, 여기서는 LoRA가 연결된 attention 포함 checkpoint의 구성을 표시합니다.

Visual channels: 64 → 128 → 256 → 256 → 512* → 1024* → 2048 → 2048
Audio channels: 32 → 64 → 128 → 256* → 512* → 1024 → 2048
* self-attention 포함 stage · 각 stage에 residual/downsampling 구성

KoNet은 이 두 encoder의 attention projection 16곳에 rank-8 LoRA를 추가합니다. 원본 401,306,080개는 고정하고 147,456개 adapter 파라미터를 학습합니다. 2D encoder의 입력에서 16프레임은 RGB 채널 축으로 쌓이며, 3D convolution과는 구분됩니다.

논문 §3.3 ↗ · 실제 attention 설정 ↗ · 두 encoder·L2 정규화 코드 ↗

최종 생성 모델을 위한 감독 요소 목표는 애니메이션 캐릭터의 한국어 더빙입니다. 위 구조는 입 영상을 생성하는 모델이 아니라, 생성 영상과 목표 음성의 sync loss를 계산할 supervisor입니다. 현재 KoNet 한국어 적응 결과를 바탕으로 애니메이션 감독·생성기 연결을 후속 단계에서 검증할 계획입니다.

데이터로 도메인 차이를 줄입니다.

현재는 한국어 supervisor 적응, 다음은 애니메이션 도메인 적응과 한국어 더빙 생성 모델입니다.

01 / DATA

한국어 paired input

AIHub 538 기반 고정 40,000쌍을 사용합니다. 같은 구간의 정합 쌍과 시간차 비정합 쌍을 균형 구성하고, 별도 validation으로 성능을 확인합니다.

02 / ADAPT

두 encoder의 LoRA

기존 401,306,080개 파라미터는 고정합니다. 양쪽 self-attention의 16개 Q/K/V/output projection에 rank 8·alpha 16 어댑터를 넣어 147,456개만 학습합니다.

03 / COMPARE

동일 입력, 고정 가중치

원본과 학습 checkpoint를 같은 validation에서 비교합니다. Signed80을 주지표로 보고 BA·BCE와 방향별 결과를 함께 확인합니다. 별도 held-out에서는 중심을 고정한 strict both-win으로 일반화 가능성을 추가 확인합니다.

다음 개발 목표: 한국어 감독 검증 → 애니메이션 시각 도메인 적응 → 생성기에 연결 → 캐릭터 한국어 더빙 평가. 입의 선명도, 캐릭터 정체성, 시간적 안정성과 음성–입 동기화를 함께 비교할 계획입니다.

발표 후 질문용: 실험 범위와 다음 검증

학습 초기 10epoch LR 1e-4, 이후 LR 2e-5. 원본 base를 고정하고 attention 어댑터만 학습한 LoRA 실험입니다. 이전 full fine-tuning 실험과 설정·학습 이력이 달라 단일 요인 ablation으로 해석할 수 없습니다.

검증 화자 4명은 작은 평가 집합입니다. 정밀 offset·화자별 변동·영어 유지 성능과 독립적인 실제 timing 정답을 확대 검증하고, 이후 생성기에 연결해 한국어 결과의 개선 여부를 확인합니다. 화자 범위와 독립적인 시간 정답 주석을 확대하는 것이 다음 평가 과제입니다.
